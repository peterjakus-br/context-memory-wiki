Context Language Models (Shao et al., arXiv:2609.37725, 2026): the agent's
context lives in a file that the agent itself can edit, including removing
information. It is a baseline in [[actor-gatherer-framework-blog]].

## Facts
- CLM "stores context in a file that can be directly modified by the agent
  itself, giving the main agent the ability to remove information from its
  context" ([[actor-gatherer-framework-blog]]).
- 41% average single-agent accuracy ([[actor-gatherer-framework-blog]]).
